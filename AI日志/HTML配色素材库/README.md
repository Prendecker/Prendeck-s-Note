# HTML 配色素材库

## 这是什么

从 [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)（MIT 协议，108K star）挑出来的品牌设计规范（DESIGN.md）合集。
DESIGN.md 是 Google Stitch 提出的"纯文本设计系统"——把一个网站的配色、字体、组件风格写成 Markdown，丢进项目根目录，AI 照着它生成风格一致的界面。

- 获取日期：2026-10-01
- 获取方式：浅克隆仓库后按需拷贝
- 库内原有 74 家，本文件夹收录 17 家点名中的 15 家

## 已收录（15 家）

airbnb / binance / clickhouse / composio / cursor / hp / linear.app / minimax / mintlify / mistral.ai / mongodb / sentry / slack / together.ai / coinbase

每家一个文件夹，里面是 `DESIGN.md`（正主）+ `README.md`（补充说明）。

- **discord** — 原库里没有  
/

需要的话可以从库里 74 家里挑替补（claude / figma / notion / vercel / stripe / spotify 都在）。

## 用法

1. **整份参考**：把某家的 DESIGN.md 内容喂给 AI，说"照这个风格做页面"
2. **丢进项目**：把 `DESIGN.md` 拷到项目根目录，AI 编码时会自动读
3. **混搭**：可以只取一家的配色 + 另一家的排版，注明来源
