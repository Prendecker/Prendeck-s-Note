> 日期：2026-10-01（国庆）

## 一、核心哲学（今天所有点子的根）

1. **枪械分化 = 枪定弹道，弹定效果**——没有最强弹药，只有最配的枪，玩家自己算乘法 = build 感
2. **枪的短板 = 留给弹药的功课**——机枪单发低吃防御 → 穷甲弹；霰弹枪打远废 → 独头弹。不是嘴上劝玩家配弹药，是枪自己逼的
3. **让玩家有选择和表达空间**——改造件选流派、弹药选搭配、格挡选手法。"看起来更有趣"就是全部理由
4. **先出初版，社区反馈再调**——内部测试天花板很低（就一个人边打游戏边测），机制立得住，数值后面改
5. **有些设计得做了才知道**——手枪叠层就是典型，嘴算算不出来

## 二、弹药系统（从笔记《关于弹药的小想法》延伸）

- 弹药三分类：**高伤弹 / 穷甲弹 / debuff弹**
  - 高伤弹 → 狙击枪吃满
  - 穷甲弹 → 克高防，机枪的解药
  - debuff弹 → 步枪（射速叠层）和狙击枪（暴击必触发）两条完全不同的用法
- debuff 弹**叠不叠层**是关键设计决策：叠层 + 上限 → 步枪质变（倾向叠层，超模模组不怕）
- **不强制转换弹药**：枪不许把玩家的弹药改写成别的（星璇机枪那种"白嫖弹幕"可以，它是额外的、不碰弹药栏）
  - 白嫖弹语法 = 主炮吃玩家弹药（效果归玩家）+ 附加弹幕固定节奏白送（枪的身份）
  - 原版先例已验证：玛瑙爆破枪（4子弹+1爆弹）、星旋机枪（每0.583s白送追踪火箭）
- 原笔记内容保留：咖啡弹（双方 DoT/增益）、魔法药盒（耗魔的无尽弹袋）、成就"你的枪什么都能射是吧？"
- ⚠️ 待办：自定义 debuff 吃不吃得到催化手环的翻倍？（原版大概率写死 buff ID）——两条路：蹭原版毒/火类型，或自己做"催化"体系。**1.4.5 配件在咱版本没有，此问题搁置**

## 三、五枪家族


| 枪型  | 定位          | 强项         | 短板          | 自带特殊效果    |
| --- | ----------- | ---------- | ----------- | --------- |
| 霰弹枪 | 贴脸类近战       | 贴脸爆发       | 散布大、打远废     | 右键格挡（给最多） |
| 机枪  | 高射速 buff 挂枪 | 射速天花板、弹药连招 | 单发低、吃防御     | 内置弹药轮换    |
| 狙击枪 | 一发入魂        | 单发天花板      | 射速低、容错差     | 暴击触发弹药特效  |
| 手枪  | 暴击叠层流       | 暴击上限高      | 基础伤害低、打不满拉胯 | 暴击体系      |
| 步枪  | 均衡画布        | 没有明显短板     | 也没有明显长板     | 弱·特殊效果    |


### 霰弹枪（聊得最深的一把）

- **类近战定位**：散布从"惩罚"变成"距离奖励"，越近弹丸全吃伤害最大化；距离管理 = 玩法
- **格挡（右键）**，魂系两档：
  - **普通格挡**：按住全程生效，伤害减免 40~70%（数值待定，可能耗弹药）
  - **完美格挡**：右键按下后 ~0.2s 窗口，**伤害归零 + 给无敌帧**（建议 ≤0.6s，不然十字项链没得翻）
  - 窗口可视化 = **金光**（暂定）
  - 手感 = 拿枪托把人肘飞（笑）
- **完美格挡奖励**（可全要）：敌人硬直 / 下一发必暴或弹丸翻倍 / 反弹伤害
- **十字项链联动**：原版无敌帧翻倍无缝继承 → 中期学会弹反是贴脸入场券，后期项链撑大窗口 = 枪托侠成型
- **连续弹反 = 连续无敌**：高手站桩的极限操作奖励
- **改造件饰品（三选一，互斥）**：
  - **鸟蛋**（鸟弹 birdshot）：弹丸大增（6→18？）单丸伤害 ×40%，铺面/挂 debuff
  - **鹿弹**：默认基准
  - **独头弹**：1 发，按原弹丸数放大伤害和暴击（600% 总伤级别，和狙击枪掰手腕）
  - 互斥方案两条路：A 装备时检查 / B 一个饰品右键切模式（混沌弹筒同款，倾向 B）
- **实现架构**：`DefaultToShotgunWeapon` 扩展方法（模仿 DefaultToRangedWeapon 风格），内部 = 设默认值 + 把 `(枪ID→弹丸数)` 写进静态字典；饰品读字典
- **三档兼容**：本模组（字典完整体）/ 原版（手动登记）/ 其他模组（兜底或不生效，tooltip 显示"枪械类型：未知"，用 GlobalItem.ModifyTooltips 实现）
- **原版霰弹枪名单（已查 wiki 核实，就 4 把）**：猎枪 Boomstick(2发)、霰弹枪 Shotgun(4-5发)、玛瑙爆破枪 Onyx Blaster(4发)、战术霰弹枪 Tactical Shotgun(4发)
  - 链炮 Chain Gun 是机枪不是霰弹（散布来自连射随机角）；海啸是弓；**珊瑚枪不存在（AI 编的，已处刑）**

### 机枪

- 内置弹药轮换：**隔几发切换一次**，切换顺序按弹药栏从上到下（可控才叫 build，随机只是彩蛋）
- 弹药栏从"仓库"变成"技能栏"，整理背包 = 编排连招
- 切换节奏"隔几发"可随枪走 → 武器家族登记系统一套架构复制粘贴（DefaultToShotgunWeapon / DefaultToMachineGunWeapon…）
- 成就进化方向：一把枪 5 秒内把所有弹药打出去

### 狙击枪

- **暴击 = 扳机**：暴击时必然触发子弹特殊效果（普通枪要戴"暴击扳机"类饰品才有，且建议给缩水版——50% 强度或内置冷却，保住狙击枪完全体地位）
- 暴击倍率不是 ×2，是 **×3/×4 甚至动态暴击**（越低血/越远/越连续命中倍率越高 → 操作奖励哲学）
- **暴击率 = 扳机可靠率**：30% 时 DoT 断断续续，70% 时 build 成型，堆暴击有全新理由
- 饰品越多狙击枪额外多薅一份（否则被机枪的每秒触发次数碾死）——要么专属狙击饰品，要么"通用饰品对狙击枪多 +X%"（后者会倒逼 DefaultToSniperWeapon 登记）

### 手枪

- 原版手枪家族可怜：手枪 / 凤凰爆破枪 / 左轮手枪，全是过渡货
- 灵感源：**《Undertale》没子弹的枪（Empty Gun）**——"必须精确地使用它，否则伤害会非常低"（12 ATK 上限高）vs **烧焦平底锅**（10 ATK"伤害更加一致"+消耗品多回 4HP）
  - 教科书级对照：**高上限不稳定 vs 低上限稳定**，"打不准不如平底锅"
  - （UTY 狂野左轮是六判准圈 3.5× 那套，真善结局掉垃圾堆变正传空枪——一条线）
- 机制方向：**暴击叠层**——连续暴击攒层，每层 +暴伤，**有一发没暴全清**（赌上全部的滚雪球）
  - 狙击枪 vs 手枪的暴击区分：狙 = 暴击用来**触发**，手枪 = 暴击用来**打伤害**
  - "全部完美命中才高伤害"的泰拉翻译候选：A 每第 3 发必暴（RNG 变节奏）/ B 瞄准同目标不移动 X 秒下一发必暴（屏息瞄准）
- 暴击养成双轨：**哥布林敲幸运**（前中期 +2% 词缀）→ **暴击饰品**（中后期大头）
- "先苦后甜"曲线 = 养成动机：成型前不如平底锅，成型后暴击永动机
- 凤凰爆破枪的升级方向（同套机制做出升级感）：+暴伤？+初始层数？升级不清层？
- **状态：做了才知道**，初版随手写个数（连续暴击每层 +10% 暴伤、3 层封顶、未暴全清）→ 打一轮 → 自问"愿意用它打完整场 Boss 吗"

### 步枪

- 均衡 = 平庸 = 没人玩，但留了个活口：**弹药放大器**（弹药特效 +20~30%，本身不触发但触发了比别人强）
- 定位 = "弹药系统的亲儿子"：不知道配啥弹？先拿步枪试
- 备选：B 微追踪精准 / C 弱·全面（全都一点点）
- ⭐ 机枪进来后步枪还站得住吗？——上面就是答案（弹药放大是机枪没有的）

## 四、"暴击为主还是辅助"的五枪暴击版图


| 枪型  | 暴击的角色                  |
| --- | ---------------------- |
| 狙击枪 | 暴击 = **扳机**（触发弹药特效）    |
| 手枪  | 暴击 = **主输出**（伤害大头在暴击里） |
| 霰弹枪 | 暴击 = 顺带（格挡才是主角）        |
| 机枪  | 暴击 = 弱化（吃 debuff 不吃暴击） |
| 步枪  | 暴击 = 均衡的一部分            |
