## 0. 起点：原版近战的问题

Prendeck 的观察：**原版近战后期容易变成「拿着刀的射手」**。

三层病根：

1. 近战弹幕零成本（射手烧弹药、法师烧蓝，近战白嫖）
2. 弹幕吃近战伤害加成，白嫖远程职业的输出模式还更耐揍
3. 后期怪物弹幕海逼你别贴脸 → 原版不断给剑加射程 → 身份丢失

## 1. 核心思路：用「格挡」把玩家请回贴脸距离

不走「距离增伤硬逼贴脸」的数值路线，而是给近战一套**类魂系格挡**——让贴脸本身成为有交互、有爽点的主动选择。

**格挡系统基本盘：**


| 档位   | 效果                           |
| ---- | ---------------------------- |
| 普通格挡 | 固定 **45% 减伤**                |
| 完美格挡 | **无视该伤害** + 获得一个**跟武器有关的强化** |


- 默认按键：**右键**
- 完美格挡的强化跟武器绑定 → 每把武器都有「格挡彩蛋」，收集动力 +1

## 2. 右键职责：按武器类别拆分（已敲定）


| 武器类    | 右键功能        | 定位           |
| ------ | ----------- | ------------ |
| **剑类** | 格挡（普通/完美两档） | 静 · 站住脚跟正面硬吃 |
| **长矛** | 冲刺（带无敌帧）    | 动 · 进出战场打了就跑 |


→ 右键冲突从根上消解：**每把武器的右键 = 它的「防身术」**。以后锤、斧等新类别可以各配一个专属右键，变成收集要素。

### 2.1 长矛右键：冲刺

- 冲刺一小段距离，**期间给无敌帧**
- 撞到怪物有两种效果（待定是「不同长矛各自绑定」还是「一武器双模式」）：
  - **反弹**：像弹珠在怪堆里来回弹 → 清群、节奏流
  - **穿透**：直接透体而过，终点可控 → 精准切入、一击脱离

### 2.2 剑类格挡的进阶细节

- 常规剑格挡**有前摇，误判会卡手** → 玩家必须**预判 boss 出招**（知识型）
- 这条为短剑的差异化埋了伏笔（见 §4）

## 3. 身份边界：近战弹幕限制在一屏幕

- 大部分常规近战武器虽有弹幕，但**射程不超过一个屏幕**
- 配套叙事：**「弹幕负责让你留在中距离，格挡负责让你敢走进去」**
- 近战远程化不禁止，但只降格为「起手/蹭血/衔接」，主力伤害得贴脸砍

## 4. 短剑：格挡系统的「容错特化型」

**背景**：原版短剑断档严重（开局几把金属短剑 + 后期几乎绝迹），空档大、值得填。

**三件套设计：**


| 维度     | 常规剑类           | 短剑                          |
| ------ | -------------- | --------------------------- |
| 格挡起手   | 有前摇，失误卡手       | **触发很快**                    |
| 完美格挡难度 | 要掐时机           | **容易触发**                    |
| 完美格挡收益 | 完全免疫 + 武器强化    | **85% 减伤**（不再是免疫）+ **弹幕偏转** |
| 练习曲线   | 背 boss 招式（知识型） | 见招拆招（反应型）                   |


**弹幕偏转（短剑独占机制）：**

- 格挡期间按概率将敌方弹幕偏转掉，**部分弹幕无法偏转**（建议按体积直觉化：大弹幕偏不动）
- 回答了「短剑射程短凭什么贴脸活下来」——弹幕偏转就是它的移动盾牌
- 待定：偏转后弹幕**消失 / 反弹打最近敌人 / 随机弹开**（反弹回去最爽，但要注意伤害归属和免疫帧，参考 `LIVG_PIIU_GLue` 的经验）

**攻击端**：短剑挥击本身也会**加一点弹幕补距离**（怎么做还没想，待议）。

## 5. 奥术武器：职业模糊的第二根柱子

- 定义：**消耗魔力强化自身**的一类武器，近战/远程都有
- 本质：让那两个不耗魔的职业开始耗魔 → 魔力变成跨职业的通用强化货币
- **强化是自动的**：有蓝且足够 → 消耗魔力强化攻击；没蓝 → 素体形态
- 关键注意点：**强化必须看得见**（弹幕变色/拖尾/贴图发光），否则玩家只觉得「蓝怎么老不够」，感受不到钱花哪了
- 实现提示：`player.CheckMana(item, true)` 通用扣蓝，大概率不需要像 `Toy_Knife` 那样手写魔力系统（Toy_Knife 特殊是因为还有挥砍计数逻辑）
- 连锁红利：近战/射手开始**抢魔力回复词条**，职业模糊的装备价值也随之模糊

## 6. 武器类型加不加——三问筛子

1. 原版在这个类型上做得够不够差？（差 = 空间大）
2. 能不能挂上已立起来的系统？（右键防身术 / 格挡 / 奥术）
3. 实现成本配不配得上收益？

**结论排序：**


| 类型  | 结论     | 理由                      |
| --- | ------ | ----------------------- |
| 短剑  | ✅ 优先   | 原版最惨、天生贴脸系、实现简单         |
| 回旋镖 | ✅ 值得加  | 后期断档、去回 AI 现成、天然契合奥术    |
