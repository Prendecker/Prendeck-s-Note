## 1. 源码获取

### 从哪里下载

- **tModLoader 内置**：模组浏览器 → 右键模组 → 查看源代码
- **GitHub**：灾厄公开仓库 https://github.com/CalamityTeam/CalamityModPublic
  - 分支选 1.4.4（对应 tModLoader stable）

### 灾厄的开源协议

灾厄用的是自创协议，核心要点：
- 可以参考源码学习
- 复制代码必须署名 Azafure, LLC 并附仓库链接
- 不能重新分发 Calamity 本身

### 文件结构

CalamityMod/
├── Items/              ← 武器、饰品、材料
├── Projectiles/        ← 弹幕
├── NPCs/               ← NPC和Boss
├── Effects/            ← 视觉效果
├── Utilities/          ← 工具类
└── CommonProjectileAI.cs  ← 通用弹幕AI

## 2. 阅读策略：不要从头读到尾

### 目标导向阅读法

错误方式：从第一个文件开始一行一行读 → 读到第100行就困了

正确方式：
1. 先确定"我想学什么"（比如：追踪弹幕怎么写）
2. 用搜索功能找相关代码
3. 只读相关的部分

### 搜索技巧

Ctrl+Shift+F → 全局搜索（最常用！）

搜索关键词示例：
- FindClosestNPC → 找追踪弹幕的代码
- Projectile.NewProjectile → 找弹幕发射的代码
- Dust.NewDust → 找粒子特效的代码
- ai[0] → 找弹幕 AI 状态机的代码

## 3. 从武器反推实现

### 分析流程

拿到一个武器文件，按这个顺序读：

1. SetDefaults() → 看它设置了什么属性
2. Shoot()       → 看它怎么发射弹幕
3. CanUseItem()  → 看它有什么使用条件
4. ModifyXXX()   → 看它有什么自定义修改

### 逐行分析示例

以 Toy_Knife 为例：

SetDefaults() 分析：
- Item.damage = 50        → 基础伤害50
- Item.useTime = 20       → 攻速中等
- Item.mana = 10          → 消耗魔力（近战用魔力，非标准！）

Shoot() 分析：
- 检查 swingCount 计数器
- 每3次攻击发射一次特殊弹幕
- return false → 已手动发射

结论：这是一个用魔力系统强化攻击的近战武器

## 4. 从弹幕反推 AI

### AI 钩子结构

Projectile.ai[0] 和 Projectile.ai[1] 是弹幕的"记忆空间"

常见用法：
- 计时器：Projectile.ai[0] += 1f
- 状态机：switch (Projectile.ai[1]) 切换不同行为
- 存储目标ID：int targetIndex = (int)Projectile.ai[0]

### localAI[] 的区别

- ai[] 会同步到多人游戏的其他客户端
- localAI[] 只在本机有效
- 一般用 ai[]

## 5. 识别常见模式

### 追踪弹幕

伪代码：找到最近的NPC → 计算方向 → 逐步转向目标 → 设置速度

代码模式：
NPC target = Projectile.Center.FindClosestNPC(800f);
if (target != null)
{
    Vector2 direction = (target.Center - Projectile.Center).SafeNormalize(Vector2.Zero);
    Projectile.velocity = Vector2.Lerp(Projectile.velocity, direction * speed, 0.1f);
}

### 散射弹幕

伪代码：循环N次 → 计算角度偏移 → 发射弹幕

代码模式：
int count = 5;
for (int i = 0; i < count; i++)
{
    float angle = MathHelper.ToRadians(-30 + i * 15);
    Vector2 newVel = baseVelocity.RotatedBy(angle);
    Projectile.NewProjectile(..., newVel, ...);
}

### 分段弹幕

伪代码：弹幕飞行 → 到达某位置 → 消失 → 分裂成多个新弹幕

代码模式：
if (Projectile.timeLeft <= 30)
{
    for (int i = 0; i < 4; i++)
    {
        Vector2 vel = Projectile.velocity.RotatedBy(MathHelper.ToRadians(i * 90)) * 0.5f;
        Projectile.NewProjectile(Projectile.Center, vel, ModContent.ProjectileType<碎片>(), ...);
    }
}
