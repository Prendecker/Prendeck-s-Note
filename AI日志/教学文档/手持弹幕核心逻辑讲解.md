## 二、ai 数组分配表

手持弹幕的 `Projectile.ai[]` 和 `Projectile.localAI[]` 是它存储状态的地方：

| 变量 | 存储位置 | 类型 | 作用 |
|------|---------|------|------|
| `Projectile.ai[0]` | `ai[0]` | float | **渐强计时器**（spinupTimer），每帧+1 |
| `Projectile.ai[1]` | `ai[1]` | float | **射击冷却倒计时**（shootTimer），倒数到0就射击 |
| `Projectile.localAI[0]` | `localAI[0]` | float | **当前等级**（0/1/2） |

> 💡 为什么用 float？因为 tModLoader 的 ai[] 只有 float 类型。
> 存整数（0、1、2）时直接用 float，比较时用 `(int)Projectile.localAI[0]` 转换。

## 三、AI() 方法逐段拆解

### 第一段：基础持有逻辑（7行骨架）

这段代码**每个手持弹幕都必须有**，作用是让弹幕"粘"在玩家手上：

```csharp
Player player = Main.player[Projectile.owner];                    // 获取持有者
Vector2 P_C = player.RotatedRelativePoint(player.MountedCenter); // 玩家手持中心

Projectile.direction = Projectile.velocity.X < 0 ? -1 : 1;       // 左右朝向
Projectile.spriteDirection = Projectile.direction;                // 贴图翻转
player.ChangeDir(Projectile.direction);                           // 玩家转身

player.heldProj = Projectile.whoAmI;        // ⭐ 告诉游戏：这是我的手持弹幕
player.SetDummyItemTime(2);                  // 保持"使用中"状态

Projectile.Center = P_C;                     // 弹幕=玩家手持位置

float offset = Projectile.spriteDirection == -1 ? MathHelper.Pi : 0;
Projectile.rotation = Projectile.velocity.ToRotation() + offset;  // 朝向鼠标
player.itemRotation = (Projectile.velocity * Projectile.direction).ToRotation();

Projectile.timeLeft = 2;                     // 每帧刷新，永续存活
```

#### 逐行解释

| 行 | 代码 | 作用 | 为什么必须有 |
|----|------|------|------------|
| 1 | `Main.player[Projectile.owner]` | 拿到玩家对象 | 需要知道谁在用这把枪 |
| 2 | `RotatedRelativePoint(MountedCenter)` | 计算手持精确坐标 | 弹幕要显示在玩家手上，不是脚上 |
| 3 | `direction = velocity.X < 0 ? -1 : 1` | 判断左右 | 决定贴图是否需要水平翻转 |
| 4 | `spriteDirection = direction` | 应用翻转 | 让枪口朝向正确 |
| 5 | `ChangeDir(direction)` | 让玩家转身 | 你拿枪指着左边，角色也要面向左边 |
| 6 | `heldProj = whoAmI` | **注册手持弹幕** | 游戏会用这个弹幕替换玩家手臂动画 |
| 7 | `SetDummyItemTime(2)` | 保持使用状态 | 没有这行，玩家按其他键会打断 |
| 8 | `Center = P_C` | 弹幕跟随玩家 | 不加这行弹幕会飘在原地 |
| 9-10 | `rotation = velocity.ToRotation()` | 朝向鼠标 | 枪口要指着鼠标方向 |
| 11 | `itemRotation = ...` | 手臂动画角度 | 让玩家手臂跟着枪旋转 |
| 12 | `timeLeft = 2` | 防止消失 | 手持弹幕需要一直存在 |

### 第二段：渐强计时器

```csharp
Projectile.ai[0]++;   // spinupTimer 每帧+1
Projectile.ai[1]--;   // shootTimer 每帧-1（倒计时）
```

**为什么这么简单？**

因为 ai[0] 就是记录"这把枪已经持续射击了多少帧"。
- 0帧 = 刚开始
- 120帧 = 2秒
- 360帧 = 6秒

**ai[1] 是射击倒计时**：
- 每次射击完重置为 `shootInterval`
- 每帧 -1
- 到 0 就该射下一发了

### 第三段：等级切换（switch-case）

```csharp
float currentTier = Projectile.localAI[0];  // 读取当前等级

switch (currentTier)
{
    case 0:  // 还在0级
        if (Projectile.ai[0] >= 120f)  // 射了2秒？
        {
            Projectile.localAI[0] = 1f;  // 升到1级！
            SoundEngine.PlaySound(SoundID.Item15);  // 升级音效
            // 生成20个火花粒子
            for (int i = 0; i < 20; i++)
                Dust.NewDust(...);
        }
        break;

    case 1:  // 还在1级
        if (Projectile.ai[0] >= 360f)  // 射了6秒？
        {
            Projectile.localAI[0] = 2f;  // 升到2级！
            SoundEngine.PlaySound(SoundID.Item36);  // 更强的音效
            // 生成30个火花粒子（更多！）
            for (int i = 0; i < 30; i++)
                Dust.NewDust(...);
        }
        break;

    case 2:  // 已满级
        // 每30帧生成1个火花，表示"满级状态"
        if (Projectile.ai[0] % 30f == 0f)
            Dust.NewDust(...);
        break;
}
```

#### 等级切换时间线

```
0帧──────120帧──────────────360帧────────→
│  等级0  │    等级1    │    等级2（满级）   │
│ 38帧/发 │  29帧/发    │  20帧/发          │
│ 10°散射 │  5°散射     │  2°散射           │
│ 1x伤害  │  1.2x伤害   │  1.5x伤害         │
│         │  💥20粒子   │  💥30粒子+持续火花 │
```

#### 为什么用 switch-case 而不是 if-else？

因为等级只会**递增**（0→1→2），不会跳级。
用 switch-case 清晰地表达"当前在哪个等级，该做什么"。
每个 case 里只处理"从当前等级升到下一级"的逻辑。

### 第四段：射击逻辑

这是弹幕**自己发射子弹**的部分——不是在 ModItem.Shoot() 里做的！

```csharp
// 1. 计算射击间隔
int shootInterval = (int)(38f - 9f * currentTier);
// tier 0 → 38帧（0.63秒/发）
// tier 1 → 29帧（0.48秒/发）
// tier 2 → 20帧（0.33秒/发）

// 2. 检查是否该射击了
if (Projectile.ai[1] <= 0f)
{
    // 3. 重置倒计时
    Projectile.ai[1] = shootInterval;

    // 4. 从背包选弹药
    int projType = ProjectileID.Bullet;
    int projDamage = Projectile.damage;
    float projKnockback = Projectile.knockBack;
    player.PickAmmo(player.HeldItem, ref projType, ref projDamage, ref projKnockback, 0);

    // 5. 计算散射
    float spread = currentTier switch {
        0 => MathHelper.ToRadians(10f),  // 10度
        1 => MathHelper.ToRadians(5f),   // 5度
        _ => MathHelper.ToRadians(2f)    // 2度
    };

    // 6. 计算枪口位置（从弹幕中心向前偏移）
    Vector2 muzzleOffset = Projectile.velocity.SafeNormalize(Vector2.UnitX) * 40f;
    Vector2 spawnPos = Projectile.Center + muzzleOffset;

    // 7. 计算射击方向 + 散射
    Vector2 shootVelocity = Projectile.velocity.SafeNormalize(Vector2.UnitX);
    shootVelocity = shootVelocity.RotatedByRandom(spread);

    // 8. 计算伤害加成
    float damageMultiplier = currentTier switch {
        1 => 1.2f,  // +20%
        2 => 1.5f,  // +50%
        _ => 1f
    };

    // 9. 发射子弹！
    Projectile.NewProjectile(
        Projectile.GetSource_FromAI(),
        spawnPos,
        shootVelocity * 12f,
        projType,
        (int)(projDamage * damageMultiplier),
        projKnockback,
        Main.myPlayer
    );

    // 10. 播放射击音效
    SoundEngine.PlaySound(SoundID.Item11, Projectile.Center);
}
```

#### 射击流程图

```
ai[1] 倒计时到 0
    ↓
重置 ai[1] = 38 - 9 × tier
    ↓
PickAmmo() → 从背包选弹药
    ↓
计算散射角度（tier越高越精准）
    ↓
计算枪口位置（弹幕中心 + 40像素偏移）
    ↓
NewProjectile() → 发射子弹！
    ↓
播放音效
```

#### 关键：PickAmmo 和 NewProjectile

| 方法 | 作用 | 谁调用的 |
|------|------|---------|
| `player.PickAmmo()` | 从背包找合适的弹药，返回弹幕类型和伤害 | 手持弹幕的 AI() |
| `Projectile.NewProjectile()` | 在世界中生成一个新弹幕 | 手持弹幕的 AI() |

> ⚠️ 注意：`NewProjectile` 是在**弹幕的 AI()** 里调用的，不是在 ModItem.Shoot() 里！
> 这就是"自管型"架构的核心——弹幕自己管自己的射击。

## 四、受伤重置（ModPlayer）

### ProgressiveGunPlayer.cs

```csharp
public class ProgressiveGunPlayer : ModPlayer
{
    public override void PostHurt(Player.HurtInfo info)
    {
        // 遍历所有弹幕，找到属于这个玩家的 ProgressiveGun_Held
        foreach (var proj in Main.projectile)
        {
            if (proj.active                                    // 弹幕还活着
                && proj.owner == Player.whoAmI                // 是这个玩家的
                && proj.type == ModContent.ProjectileType<ProgressiveGun_Held>())  // 是这把枪
            {
                proj.ai[0] = 0;       // 重置渐强计时器
                proj.ai[1] = 0;       // 重置射击冷却
                proj.localAI[0] = 0;  // 重置等级为0
            }
        }
    }
}
```

#### 为什么用 ModPlayer 而不是在弹幕里检测？

弹幕**不知道**玩家有没有被打——它只管自己。
被打是**玩家**的事件，所以需要在 ModPlayer 里监听。

调用链：
```
玩家被打 → 游戏调用 ModPlayer.PostHurt()
         → 遍历弹幕找到 ProgressiveGun_Held
         → 重置 ai[0]/ai[1]/localAI[0]
         → 下一帧弹幕 AI() 发现等级为0，回到最慢射速
```

## 五、音符弹幕（NoteProjectile）

### 波浪飞行原理

```csharp
public override void AI()
{
    // 第一帧：保存初始方向
    if (Projectile.localAI[0] == 0f)
    {
        Projectile.localAI[0] = Projectile.velocity.X;
        Projectile.localAI[1] = Projectile.velocity.Y;
    }

    // 递增相位
    Projectile.ai[0] += 0.15f;

    // 计算波浪偏移（正弦波）
    float amplitude = 8f;
    float waveOffset = MathF.Sin(Projectile.ai[0]) * amplitude;

    // 垂直方向 = 速度的法线方向
    Vector2 perp = new Vector2(-Projectile.localAI[1], Projectile.localAI[0]).SafeNormalize(Vector2.Zero);

    // 最终速度 = 原始方向 + 波浪偏移
    Projectile.velocity = new Vector2(Projectile.localAI[0], Projectile.localAI[1]) + perp * waveOffset;
}
```

#### 正弦波可视化

```
    ╭─╮     ╭─╮     ╭─╮
───╯  ╰───╯  ╰───╯  ╰───→  前进方向
         sin 波形
         
ai[0] 递增 → sin(ai[0]) 在 -1~1 间振荡
乘以 amplitude(8) → 偏移量在 -8~8 像素间振荡
垂直叠加到速度方向 → 波浪飞行
```

## 六、完整数据流

```
玩家按住左键
    │
    ▼
ModItem.Shoot() → 发射 ProgressiveGun_Held (return false)
    │
    ▼
ProgressiveGun_Held.AI() 每帧执行：
    │
    ├─ [基础] 跟踪玩家位置、旋转、heldProj
    │
    ├─ [渐强] ai[0]++ → 120帧升1阶 → 360帧升2阶
    │         每次升级：播放音效 + Dust粒子
    │
    ├─ [射击] ai[1]-- → 到0时：
    │         PickAmmo() → 拿弹药
    │         计算散射（10°/5°/2°）
    │         NewProjectile() → 发射子弹
    │         播放音效
    │
    └─ [动画] 播放帧动画（6帧循环）
    
玩家被打
    │
    ▼
ModPlayer.PostHurt() → 找到弹幕 → 重置 ai[0]/ai[1]/localAI[0]
    │
    ▼
下一帧 AI() 发现等级=0 → 回到最慢射速
```
