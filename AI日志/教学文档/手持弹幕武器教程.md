## 一、什么是手持弹幕武器？

### 普通武器 vs 手持弹幕武器

| | 普通武器 | 手持弹幕武器 |
|---|---------|------------|
| 显示方式 | 玩家挥枪/拉弓，游戏默认动画 | 用一个弹幕替换玩家手臂 |
| 朝向控制 | 粗略（只分左右） | 精确（360°跟随鼠标） |
| 动画控制 | 受限于物品帧数 | 弹幕自己控制动画速度 |
| 适用场景 | 大部分武器 | 枪械、蓄力武器、复杂射击模式 |

### 典型例子

- **普通**：迷你鲨（用原版手臂动画）
- **手持弹幕**：示例模组的 ExampleHeldProjectileWeapon
- **渐强型**：灾厄的赤陨霸龙弓（越射越快）

## 二、架构拆解 — 以你的 Shadow_Guny 为例

### 两种架构

#### 架构 A：简单型（Shadow_Guny 现在的）

```
ModItem.Shoot() 负责发射所有子弹
手持弹幕只管"显示"，不发射子弹
```

**代码流程**：
```
玩家左键 → Shoot() → 发射普通子弹 (return true)
玩家右键 → Shoot() → 发射 Shadow_Guny_Htelm 手持弹幕 (return false)
                      手持弹幕只跟踪玩家位置，不发射任何东西
```

#### 架构 B：自管型（灾厄 + 示例模组）⭐ 本教程用这个

```
ModItem 只负责：设定属性 + 启用手持弹幕
手持弹幕的 AI() 自己管：渐强计时 + 射击间隔 + 弹药消耗 + 发射子弹
```

**代码流程**：
```
玩家左键 → Shoot() → 发射 ProgressiveGun_Held 手持弹幕 (return false)
                      手持弹幕 AI() 每帧：
                        ├─ 渐强计时（spinupTimer++）
                        ├─ 检查是否该射击（shootTimer 倒计时）
                        ├─ PickAmmo() 消耗弹药
                        ├─ NewProjectile() 发射子弹
                        └─ 跟踪玩家 + 旋转 + 播放动画
```

### 为什么选架构 B？
- 渐强逻辑和射击逻辑在一起，不用跨文件协调
- 灾厄和示例模组都是这么做的（成熟方案）
- 更容易实现射速/伤害/散射的动态变化

## 三、手持弹幕 AI 的核心代码

### 7 行骨架（每个手持弹幕都必须有）

```csharp
public override void AI()
{
    Player player = Main.player[Projectile.owner];                    // ① 获取玩家
    Vector2 P_C = player.RotatedRelativePoint(player.MountedCenter); // ② 玩家手持中心点

    // ③ 方向控制
    Projectile.direction = Projectile.velocity.X < 0 ? -1 : 1;
    Projectile.spriteDirection = Projectile.direction;
    player.ChangeDir(Projectile.direction);

    // ④ ⭐ 告诉游戏"我手持这个弹幕"
    player.heldProj = Projectile.whoAmI;

    // ⑤ 保持"使用中"状态（防止玩家切换物品）
    player.SetDummyItemTime(2);

    // ⑥ 弹幕跟随玩家 + 旋转朝向
    Projectile.Center = P_C;
    float offset = Projectile.spriteDirection == -1 ? MathHelper.Pi : 0;
    Projectile.rotation = Projectile.velocity.ToRotation() + offset;
    player.itemRotation = (Projectile.velocity * Projectile.direction).ToRotation();

    // ⑦ 每帧刷新存活时间（永续弹幕）
    Projectile.timeLeft = 2;
}
```

### 每行的作用

| 行 | 作用 | 为什么必须有 |
|----|------|------------|
| ① | 获取持有此弹幕的玩家 | 需要读取玩家数据 |
| ② | 计算玩家手持的精确位置 | 弹幕要显示在玩家手上 |
| ③ | 让玩家朝向弹幕方向 | 玩家角色会转身面向射击方向 |
| ④ | 注册为"手持弹幕" | 游戏会用这个弹幕替换玩家手臂 |
| ⑤ | 保持使用状态 | 防止弹幕存在时玩家能切换物品 |
| ⑥ | 位置 + 旋转 | 弹幕显示在正确位置并朝向鼠标 |
| ⑦ | 防止弹幕消失 | 手持弹幕需要一直存活 |

## 四、渐强系统设计

### 参考：灾厄 DrataliornusBow 的实现

灾厄的做法非常优雅：
```csharp
// ai[0] = 渐强计时器，每帧+1
// localAI[0] = 当前等级（0~10）
switch ((int)Projectile.ai[0])
{
    case 36:  case 72:  case 108: ... case 324:
        Projectile.localAI[0]++;  // 每36帧升一级
        break;
    case 360:
        Projectile.localAI[0]++;  // 满级！
        Projectile.ai[0] = -1f;   // 标记已满级
        // 满级特效：Dust 爆炸圈
        break;
}

// 射击间隔随等级递减
int baseUseTime = 38;
int modifier = 3;
Projectile.ai[1] = baseUseTime - modifier * Projectile.localAI[0];
```

### 我们的三阶段设计

| 等级 | spinupTimer | 射击间隔 | 伤害 | 散射 | 视觉 |
|------|-------------|---------|------|------|------|
| 0 (起步) | 0~119 | 38帧 | 1.0x | 10° | 普通 |
| 1 (中速) | 120~359 | 29帧 | 1.25x | 5° | 枪口火焰变大 |
| 2 (满速) | ≥360 | 20帧 | 1.5x | 0° | Dust爆炸 + 弹幕变色 |

### 射速公式

```
shootDelay = baseUseTime(38) - modifier(9) × tier
```

- tier 0：38帧（慢）
- tier 1：29帧（中）
- tier 2：20帧（快）

### 受伤重置

用 ModPlayer 的 `PostHurt` 钩子：
```csharp
public override void PostHurt(Player.HurtInfo info)
{
    // 找到手持弹幕，重置渐强状态
    foreach (var proj in Main.projectile)
    {
        if (proj.active && proj.owner == Player.whoAmI 
            && proj.type == ModContent.ProjectileType<ProgressiveGun_Held>())
        {
            proj.ai[0] = 0;      // 重置 spinupTimer
            proj.ai[1] = 0;      // 重置 shootTimer
            proj.localAI[0] = 0; // 重置等级
        }
    }
}
```

## 五、音符弹幕（右键副模式）

### 波浪形飞行原理

```csharp
public override void AI()
{
    // 相位递增
    Projectile.ai[0] += 0.15f;
    
    // 计算波浪偏移（正弦波）
    float amplitude = 8f;  // 波浪幅度
    float waveOffset = MathF.Sin(Projectile.ai[0]) * amplitude;
    
    // 将偏移垂直叠加到速度方向上
    Vector2 perp = new Vector2(-Projectile.velocity.Y, Projectile.velocity.X).SafeNormalize(Vector2.Zero);
    Projectile.position += perp * waveOffset;
    
    // 正常前进
    Projectile.position += Projectile.velocity;
}
```

### 关键参数

| 参数 | 值 | 作用 |
|------|-----|------|
| 波浪频率 | 0.15f | 越大波浪越密集 |
| 波浪幅度 | 8f | 越大波浪越宽 |
| 伤害倍率 | 0.75f | 右键伤害 = 基础 × 0.75 |

## 八、常见问题

### Q: 手持弹幕不显示？
A: 检查 `Main.projFrames[Type]` 是否设置了，贴图文件名是否匹配类名。

### Q: 弹幕不跟随玩家？
A: 确认 AI() 里有 `Projectile.Center = player.RotatedRelativePoint(player.MountedCenter)`。

### Q: 射速没变化？
A: 检查 `Projectile.ai[1]` 的重置值是否随 tier 变化。

### Q: 受伤后没重置？
A: 确认 ModPlayer 的 `PostHurt` 里找到了正确的弹幕并重置了 ai[0]/ai[1]/localAI[0]。
