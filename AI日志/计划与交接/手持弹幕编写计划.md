### ✅ 发光位置 & 图层 —— **根因找到并修复（09-25）**

**真凶是这一行**（不是 glow 本身的问题）：
```csharp
player.heldProj = player.whoAmI;      // ❌ 玩家索引，单人模式 = 0
player.heldProj = Projectile.whoAmI;  // ✅ 弹幕索引
```
写错的后果：游戏去 `Main.projectile[0]` 找"手持物"，弹幕根本没走手持弹幕绘制路径
→ **图层不对 + 位置不对 + 发光蒙版看着错位**，三个症状一个根因。

**三个已落地的修复**（Prendeck 自己改的）：
1. `Projectile.hide = true;` 解开注释
2. `player.heldProj = Projectile.whoAmI;`
3. `Item.noUseGraphic = true;` —— **他自己诊断出来的**（物品贴图没隐藏）

### ✅ `_Glow` 后缀贴图 = tML 自动渲染（已查证）
官方属性 `ModProjectile.GlowTexture`，默认 `Texture + "_Glow"`，**画在原贴图正上方**，共用同一套位置/旋转/帧矩形。
→ 问题清单"⑧ 孤儿贴图"的旧判断**已推翻**，不是孤儿。

Player player = Main.player[Projectile.owner];
Vector2 P_C = player.RotatedRelativePoint(player.MountedCenter);

if (Projectile.owner == Main.myPlayer && !Main.mouseRight) { Projectile.Kill(); return; }

Projectile.direction = Projectile.velocity.X < 0 ? -1 : 1;

player.SetDummyItemTime(2);

## 六、已讲的课（他已听过，别重讲）

1. **永生原理**：`AI()` 每帧 `Projectile.timeLeft = 2` = 闹钟每次快响就被按掉 → 永远不死。
   两种死法：停止续命（慢半拍） vs `Kill()` 主动自杀（**选这个**，ExampleMod 同款）
2. **条件方向**：`Main.mouseRight` 按住 = true → "没按着才死"要取反 `!Main.mouseRight`
3. **多人安全**：`Main.mouseRight` 只有主人的客户端知道 → 判决必须包在 `owner == Main.myPlayer` 里
