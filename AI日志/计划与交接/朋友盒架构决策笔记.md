## 三、硬件选型

### ✅ 已定的原则


| 项目         | 决定                 | 理由                                                          |
| ---------- | ------------------ | ----------------------------------------------------------- |
| **CPU**    | **N150**（不是 N100）  | 2025 Q1 Twin Lake，睿频 3.6 vs 3.4 GHz，**TDP 同为 6W**，买新不买旧     |
| **内存**     | **16G 起**          | Docker 清单实测 2–7G；homelab 参考表 5–10 容器 16G 舒适、15–20 容器才需要 32G |
| **硬盘**     | **1TB 起步，2TB 更好**  | 他明确要"存储高一点"；且 **NAND 4Q26 预测还要涨 15~20%**，比内存更紧迫             |
| **散热**     | **静音 / 无风扇**       | 常驻 7×24 摆桌上/床头，吵一下就输了                                       |
| **CPU 性能** | **最不值得花钱的项目**      | 大脑在云端，4 核 4 线程跑容器 idle 足够                                   |
| **功耗**     | 6W TDP / 整机约 8–15W | 一年电费几十块——**这才是"朋友盒"的核心卖点：能永远亮着**                            |


### ⚠️ 32G 内存的坑（要买 32G 必看）

- **Intel 官方规格页标称最大内存 16 GB、单通道**（N100 / N150 皆是）
- 但**实际很多主板能上 32G**（华擎 NUC-N150 工控板标 32G；京东有 N150MAX 32G 整机）
- **能不能点亮取决于主板布线 + BIOS 有没有放开** → **下单前必须逐款确认具体型号支持 32G**
- **单槽**：绝大多数 N100/N150 盒子只有一个内存插槽 → **升级 = 拔旧换新，不是加一条**

### 💰 内存/硬盘价格行情（2026-09/10 数据）

- DRAM **已涨约 4.5 倍**；DDR4 合约价 1 月 $11.50 → 9 月 $26（历史最高）
- **但涨幅连续刹车**：7 月 +14.29% → 8 月 +4.17% → 9 月 +4%
- NAND 9 月仅 +0.44%，基本横盘；消费端已现"涨价天花板"，PC/手机厂商开始砍单
- **4Q26 预测**：一般型 DRAM 季涨 10~~15%、**NAND 季涨 15~~20%**
- → **结论：现在不是好时机，但也不是恐慌期。他本来就一分没花，这个"最优策略"依然成立。**

## 七、成本控制（他最在意的一条）

**框架本身不收钱，收钱的是模型调用**：

```
API 费用 = 调用次数 × 每次 token 数 × 单价
            ↑           ↑            ↑
         框架影响     框架+你影响    模型选择
```

### 变量① 调用次数 —— 心跳必须默认关

> **心跳（heartbeat）= agent 自己定期醒来一趟，哪怕用户一句话都没说。**
> 类比手机的"后台刷新"。没有它 = 纯被动；有它 = 才能主动提醒/日报/监控。

- OpenClaw 文档原话：*"心跳目前默认每 30 分钟运行一次。在信任此配置之前，请通过 `heartbeat.every: "0m"` 禁用它"*
- 算账：**48 次/天 × 30 天 = 1440 次/月**，用户一句话没说
- QwenPaw 同样有 heartbeat 和 `jobs.json` 定时任务

> **✅ 规则：新家装好第一件事，心跳和自动任务全关掉，需要什么再开什么。**
> 主动能力是奢侈品，按次付费。

### 变量② 每次 token 数 —— 已有铁律

- **2026-09-28 已定：记忆检索走工具调用，禁止注入前缀（否则缓存全灭）**
→ 这条本身就是成本优化：前缀稳定 → 命中缓存 → 读缓存单价远低于全价输入
- ⚠️ **T_T 的文件可能就是最大成本项之一**：`SOUL.md` + `USER.md` + `FACT.md` + `AGENTS.md` 每次调用整份带上，**人设每长一行，每次调用多付一次钱**
- 📌 **待办：给 AI 的文件做"瘦身"**，把能挪进 memU 的细节挪走
—— 但按规矩：**剪之前先确认 memU 里有兜底**（2026-09-28 重构已踩过一次）

### 变量③ 模型选择 —— 分层，不搞全本地


| 场景         | 走哪               | 花钱吗        |
| ---------- | ---------------- | ---------- |
| 日常闲聊、简单问答  | 本地 2B/4B（Ollama） | **0 元**    |
| 指导、教学、复杂推理 | 云端 API           | 花钱，但只在真需要时 |


⚠️ **诚实提醒**：N100/N150 单通道带宽 → **2B 能跑、4B 勉强、9B 别想**。
而且本地 2B 陪他闲聊，**大概率会被嫌笨**——跟现在的体验差着量级。所以别指望"全本地省钱"。

## 九、GitHub 与网络（含一条省钱结论）

### ✅ 实测结论：代理**不是必须**


| 通道                                         | 状态                               |
| ------------------------------------------ | -------------------------------- |
| **git 协议**（`ls-remote` / `fetch` / `push`） | ✅ **实测通**                        |
| 网页抓取、浏览器访问 github.com                      | ❌ `ERR_CONNECTION_RESET`（国内典型症状） |


朋友盒的核心循环是：

```
git fetch 拿新提交 → 读 diff → 写 // T_T 注释 → git push
```

**这四步全走 git 协议，一个代理都不需要。**

- 代理只在两种场景用得上：浏览器看 GitHub 网页版（Issues/PR 页面）、抓第三方站点
- → **代理是锦上添花，不是"不用不行"。等真卡住了再说。**
- Prendeck 表示若需要会自己配（他清楚这话题的性质，T_T 不主动给教程）

### 部署位置

- **倾向家里盒子**：免费、数据在手、隐私好；代价是出门要打洞（Tailscale / 内网穿透）
- 云 VPS：随时可达、有公网 IP；代价是月费 + 数据在别人机房

### ⚠️ 国内部署的额外提醒

盒子放国内 → 想访问 GitHub 网页也会撞同一堵墙 → 到时候可能需要代理或镜像（Gitee 等）。

### 📚 已讲的 git 课（别重讲）

1. **三区心智模型**：工作区（硬盘）→ `git add` → 暂存区（待办清单）→ `git commit` → 仓库（存档）
2. **读 `git status**`：每行两列，第1列=暂存区、第2列=工作区；空格=没变、`M`=改了、`D`=删了
3. **三条铁律**：动手前先 `status` / **pull·push 前工作区必须干净** / commit 本地不花钱、push 才上传
4. `**git restore --staged <文件>**` = 撤回装包，硬盘不动

## 十四、参考概念（讲给 Prendeck 听过，可直接引用）

**框架分五类，互相根本不竞争：**


| 类别                | 干什么                     | 代表                                      |
| ----------------- | ----------------------- | --------------------------------------- |
| **Harness / 运行时** | 套在模型外面那层壳：循环、工具、上下文     | Claude Code、OpenCode、OpenClaw、Hermes、pi |
| **成品个人助理**        | harness + 人设 + 频道 + 控制台 | **QwenPaw**、CoPaw、知微、蓬莱                 |
| **开发框架**          | 给你**写** agent 用的 SDK    | Qwen-Agent、LangGraph、CrewAI、AutoGen     |
| **记忆层**           | 插在任何 agent 外面的记忆系统      | **Hindsight**、mem0、MemOS                |
| **协议**            | 让上面这些互相说话               | MCP、A2A、ACP                             |


**Agent = Model + Harness**：模型提供"大脑"，Harness 提供"身体"。
**模型决定上限，Harness 决定下限。**（2026 年业界共识）

**选型铁律（Prendeck 自己总结的，很准）**：

> **功能可以抄，生态抄不来。**
> 功能重叠 → 无独占优势 → 用户跑 → 周边撤 = **正反馈的死亡螺旋**，一旦开始基本不可逆。

**框架体检清单 7 项**：Star 增速（**不是总数**）/ 最近 commit / Release 频率 /
Issue 有没有人回 / 文档还更不更 / 社区渠道活着没 / **有没有人给它写周边**（最关键）
